# 模型 D：共享饱和杀伤项的第一轮比较

保持三个物理状态 CF、CB、N，仅更改现有细胞数方程的杀伤项：

```
dCF/dt = kEF*(VE/VI)*CE - (kFE+kFB)*CF + kBF*CB
dCB/dt = kFB*CF - kBF*CB
dN/dt  = kp*N*(1-N/theta) - [beta*CB/(1+CB/Ks)]*N
```

CE 为原实验给药输入，6 h 后 washout 归零；洗脱前后速率常数相同。实现仍积分 CF、CB、log(N)，未新增状态、threshold、damage-memory 或生长机制。

## 固定值和自由参数

固定参考 kEF=3.5e-6 h^-1、kFE=1.25 h^-1、kFB=0.21 h^-1、VI=0.004629 µL、VE=250 µL；来源为原始代码提交 `6325d45`。固定 full 对照组 kp=0.031094959444983555 h^-1、theta=35143.615284616222 cells，以及原 D 最佳 kBF=0.0049373889028291049 h^-1。kBF 完整双精度取自运行 `43101764836` 的 `model_d_fit.mat`。参考值不是独立实验已确定值，详见 [D 来源](model_d_definition.md)。

仅拟合跨三个剂量共享的 beta、Ks：

| 参数 | 单位 | 作用 | 本轮边界 |
| --- | --- | --- | --- |
| beta | nM^-1 h^-1 | 低 CB 时单位浓度的杀伤斜率 | `[1e-9,0.1]`，沿用现有 beta 边界 |
| Ks | nM | 半最大杀伤浓度；CB=Ks 时杀伤速率为 beta*Ks/2 | `[1e-3,1e8]`，新增探索边界 |
| beta*Ks（派生量） | h^-1 | CB 趋于大值时的最大有效杀伤速率 | 不额外独立设边界 |

边界依据：固定参考 PK 下，三剂量 CB 峰值约 24.889、49.778、99.556 nM。Ks 下界远低于这些峰值，用于覆盖强饱和区；上界高于最大峰值约一百万倍，使分母对杀伤速率的修正约为 1e-6 或更小，覆盖近线性区。这是计算探索范围，不是实验不确定性范围或生物学先验。保留 beta 原上界会限制极小 Ks 时的最大杀伤速率，因此低 Ks profile 若 beta 触界必须一并报告。

## 保持一致与优化检查

沿用全部 32 个处理组观测，目标仍为各剂量 `sum(((Npred-Nobs)/max(Nobs))^2)` 后相加。数据、残差缩放、初始细胞数、求解器 ode15s、RelTol=1e-7、AbsTol=1e-9 不变。新增 `rhsSaturation` 直接调用原 RHS 的两个 PK 导数，仅替换第三个导数中的杀伤表达式；原 `loss/simulate/rhs` 保留用于线性比较。

复用原 `multifit/fminsearch` 的迭代上限和容差。使用 8 个起点、固定 `271828/twister`，初始猜测 `[共享线性beta,50 nM]`，另增加一个 `[共享线性beta,1e7 nM]` 的近线性起点检查嵌套关系，共 9 个起点。每个起点均保存 MAT 检查点，报告退出标记、SSE 和边界距离。

Ks 条件 profile 包括全边界内 81 个对数点、联合最优 Ks 的 1/4 至 4 倍范围内 41 点、联合最优点以及显式 `Ks=Inf`。每个固定 Ks 都复用 `profileBeta` 的对数扫描、局部细化和端点比较，重新优化共享 beta。逐点保存 MAT/CSV，不把描述性的 SSE 上升范围称为置信区间，也不据此宣称 Ks 被实验唯一确定。

线性极限检查有两部分：一是保持归档共享 beta=0.00048479871747565857，分别计算 Ks=1e3、1e5、1e8、Inf，与原线性 ODE 的细胞数和有效杀伤速率直接比较；二是 profile 的 `Ks=Inf` 点重新拟合 beta，检查 SSE 是否恢复原 D。`Inf` 仅为显式数学极限，不是有限参数搜索边界。相对曲线差异定义为最大绝对差除以参考曲线全时段峰值。

## 比较与运行

保留原共享 beta 线性 D 和分剂量 beta 诊断。新模式 `saturation` 调用 `run_joint_pkpd(8,false,true,true)`，原 A/B/C/D 与 D profile 仍运行，随后执行分剂量 beta 诊断及本次共享饱和比较。Actions 手动模式或 `pkpd-saturation` 分支的相关代码 push 可以启动；仍通过 Git 自动取回结果。

`model_d_saturation_*` 文件内 model_id=1 为线性共享 beta，2 为分剂量 beta 诊断，3 为共享饱和 beta/Ks。输出每剂量曲线、逐时残差、有效杀伤速率、各剂量 SSE、联合拟合、Ks profile 和线性极限检查。拟合自由 PD 参数数分别为 1、3、2，均以已拟合 kBF 固定为条件；不将这视为外部已知参数下的正式统计检验。

这是第一轮 PD 形式比较。训练 SSE 降低不能单独证明机制更合理或预测能力提高；cell number 来自论文图像数字化，旧 CF+CB 是模拟值，不是独立实验约束或验证集。暂不联合重拟合 PK 或改变生长参数。
