# CB 驱动的两级延迟 PD：分阶段比较

暂停本轮饱和项研究，保留既有结果文件。本轮不使用 Ks、threshold、额外持续损伤或剂量相关 theta。

## 方程与单位

```
CF' = kEF*(VE/VI)*CE - (kFE+kFB)*CF + kBF*CB
CB' = kFB*CF - kBF*CB
E1' = r*(CB-E1)
E2' = r*(E1-E2)
N'  = kp*N*(1-N/theta) - alpha*E2*N
```

CF、CB、E1、E2 单位均为 nM，r 为 h^-1，alpha 为 nM^-1 h^-1，alpha*E2 为 h^-1。E1/E2 暂称效应传递状态，不解释为已测量 DNA 损伤或特定分子过程。实际求解 CF、CB、E1、E2、log(N)，没有截断 N 来制造灭绝。

零初值下，E2 为 CB 与 `r^2*tau*exp(-r*tau)` 的卷积。该核积分为 1、均值延迟为 2/r、脉冲核峰值在 1/r；实际给药下的 E2/杀伤峰值取决于整个 CB 输入，不等于一般意义上的 1/r。CB 连续且变化相对较慢、r 足够大时趋近瞬时效应。该机制借鉴暂时效应的响应形状，但不等于原文 B 的直接时间函数。

## 固定量、阶段和边界

固定参考 kEF=3.5e-6、kFE=1.25、kFB=0.21 h^-1、VI=0.004629 µL、VE=250 µL；kp=0.031094959444983555 h^-1、theta=35143.615284616222 cells。来源限制见 [D 定义](model_d_definition.md)。所有参数在 washout 前后不变，只改变 CE，不重置任何胞内或效应状态。

阶段 1 固定 D 最佳 kBF=0.0049373889028291049 h^-1，仅拟合共享 alpha、r。这个 kBF 来自瞬时 PD 在同一数据上的拟合，不是独立 PK 测量。

阶段 2 联合拟合共享 kBF、alpha、r，其余条件与阶段 1 相同。

| 参数 | 边界 | 依据 |
| --- | --- | --- |
| kBF | `[1e-7,10] h^-1` | 完全沿用原探索边界，阶段 1 固定、阶段 2 自由 |
| alpha | `[1e-9,0.1] nM^-1 h^-1` | 与原 beta 同单位，沿用原强度边界以便比较 |
| r | `[1e-4,100] h^-1` | 覆盖核峰值延迟 0.01–10000 h，包含相对数百小时观测窗口很快及很慢的响应 |

边界为计算探索范围，不是实验误差范围。两阶段分别固定 RNG `57721/twister`、`57722/twister`，复用原对数参数变换、multifit/fminsearch、MaxIter=650、MaxFunEvals=1800、TolX=1e-5、TolFun=1e-8。quick 各 2 个常规起点，full 各 8 个；各加 1 个大 r 起点检查近瞬时情形。阶段 2 的首个起点使用阶段 1 结果。

full 额外对阶段 2 的 r 做条件 profile：21 个全范围对数点，加最优 r 附近 1/4–4 倍范围的 11 点和最优点；每个固定 r 重新用 3 起点优化 kBF、alpha，记录二者补偿和触界情况。若 profile 找到更低区域，再从该点进行一次联合细化。此 profile 用于描述条件性参数补偿，不校准置信区间。

## 原文时间形式诊断与模型计数

原文定义核实后，A 使用 `kdA`，B 使用 `kdB*r*tau*exp(1-r*tau)`，tau 为核实的时间原点之后的时间。tau<0 杀伤严格为零，相关观测保留；生长和杀伤分离，kp/theta 固定，不引入 theta(D) 或将 logistic 因子乘到杀伤项。A 每剂量 1 参数、B 每剂量 2 参数，分别共 3 和 6 个参数；kd 的探索边界 `[1e-9,1] h^-1`，上界覆盖远强于对照增长率的杀伤，r 沿用上述范围。这不是原文完整模型复现，不进行 AIC 加权。

本轮输出 model_id：1=归档 D，2=分剂量 beta，3=常数时间形式诊断，4=暂时时间形式诊断，5=延迟阶段 1，6=延迟阶段 2。未核实原文时，3/4 明确标为未运行，SSE 留空。归档 D 本轮重新拟合参数数为 0（其原拟合为 kBF、beta 两个参数）；其余依次为 3、3、6、2、3。kp/theta 和参考 PK 作为共同固定条件另列，kBF 的历史估计不能当作外部已知量。
