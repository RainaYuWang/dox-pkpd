## PK、拟合和诊断定义

记 `q=kEF*(VE/VI)*CE`、`a=kFE+kFB`。当 kBF=0 时，给药期 `CF=q*(1-exp(-a*t))/a`，洗脱后 CF 以速率 a 指数消退。质量积分给出 `CB_inf=kFB/a*q*T`，即 `alpha(T)=(kEF*VE/VI)*(kFB/a)*T`。剩余未结合量在洗脱后指数消退。参考值 3.5e-6、1.25、0.21 h⁻¹ 和 0.004629、250 µL 来自仓库早期模型，正文方法节直接给出 VE=250 µL，其余沿用旧模型的参考校准（见[模型 D 参数来源](../reports/model_d_definition.md)）。它们不视为论文直接报告的统一已知速率。正 kBF 模型保留解离回流和再结合。平台表给出首次达到不可逆平台 95% 的时间、正 kBF 峰值、实际可辨观察端点及从给药和从 washout 起算的两个 600 h 对照。变化百分比相对各自峰值或不可逆渐近值，峰之后有限窗口的缓慢变化不是严格稳态。

拟合含三种输入（固定平台、动态且 kBF=0、动态并拟合共享 kBF）与三种杀伤（线性、Hill n=1、Hill 自由 n）。共享 kp；九个 theta 各组恒定且自由。Hill n=1 对应旧 `beta*CB/(1+CB/Ks)`，令 `Khalf=Ks, Kmax=beta*Ks`。常数输入时 N 单调或恒定，因此无法表达下降再回升。每个模型使用相同时间、N0 和逐组最大观察细胞数归一化的残差，再平方求和。权重不使用 CI 或重复数。早期影响以 48 h 内残差和时序图检查，48 h 不作为拟合起点或预定平台时刻。

线性 PK 在 washout 前后解析传播。设 `A(t)=∫[kp−f(CB)]dt`，从首观测开始，数值积分形式为 `N0*exp(A)/(1+(kp*N0/theta)*∫exp(A)dt)`。统一分段四点 Gauss–Legendre，最大步 0.5 h，独立分段 `ode15s` 数值检查采用 RelTol 1e-9、AbsTol 1e-11。没有人为将 N 截为零。每次试算共享参数时，逐组重优化对数 theta，以降低共享参数搜索维数。使用仓库的有界对数空间 `fminsearch` 设置和固定种子 42。近界指对数距离 ≤0.01。探索边界为 kp [1e-4, 0.12]、beta [1e-9, 0.1]、Kmax [1e-6, 1]、Khalf [1e-3, 1e7]、n [0.2, 8]、theta [100, 1e8]、正 kBF [1e-7, 10]。范围覆盖慢解离和快解离、近线性和饱和行为。界限不是生理先验。精确 kBF=0 单独运行。每个正值 profile 重新优化其余共享参数并重优化九个 theta。

## 运行与取回

现有检出目录可直接使用。MATLAB R2024b 基础版从仓库根目录运行 `matlab -batch "addpath('fig3'); run_fig3_pkpd('fig3-quick')"`。quick 采用至少 3 个起点和较粗的 kBF 网格，full 至少 10 个起点和较细网格。结果默认写入全新的 `fig3_results/`；可传第二个 MATLAB 参数指定另一个新目录。旧结果由原入口维护。

GitHub 的 Fig. 3 专用 workflow 经 `pkpd-fig3-quick` 和 `pkpd-fig3-full` 分支启动。先完成 quick 检查，再用相同的拟合代码和数据启动 full。若同一提交已通过 quick 分支推送，首次仅创建 full 分支可能因 GitHub 的路径过滤而没有运行记录。在 full 分支推送包含 Fig. 3 说明更新的提交可触发运行，再按该提交取回结果。取回精确提交和指定模式的示例：

```sh
python3 ci/collect_results.py --sha HEAD --mode fig3-quick --wait 5400
python3 ci/collect_results.py --sha HEAD --mode fig3-full --wait 15000
```

输出包括拟合及残差九宫格、CB 及杀伤速率九宫格、SSE 及自由参数数、全部起点和近界、kBF profile、时间窗和再增长诊断、数值检查与完整 MAT。全程使用 Fig. 3 可辨子集，旧三组拟合只作背景。
